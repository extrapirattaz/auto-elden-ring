# Generated background assets — 5.0.0

Produced with the built-in image generation tool on 2026-10-04, then inspected
and converted to WebP for distribution. Original generated PNG files remain in
the Codex generated-images folder. Runtime consumers use only project-local
WebP assets with a fixed readability tint.

These are original fantasy illustrations inspired by the requested moods, not
screenshots or extracted assets from Elden Ring. Changing the Elden palette
selects its corresponding background automatically.
