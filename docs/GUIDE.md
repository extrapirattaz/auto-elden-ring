# Auto Elden Ring 1.0.1 guide

This is the maintained copy of the initial calculator, not the latest companion.
Its original interface and calculations remain available for historical use.

Run the Windows x64 executable directly, or install Python 3.14 x64 and run main.py.
No third-party runtime packages are required by this historical edition.

Choose a starting class and enter current/target levels or attributes to compute
level costs. Enter a weapon's first-upgrade price or next-upgrade quote to plan
normal/somber improvements, or choose catalogue weapons. Record smithing-stone
stock and runes to calculate the remaining purchase budget. Measure a farming
session and enter its rune gain/duration to estimate time to a chosen objective.
Saved project files must be opened with the matching schema/version.

The source layout is auto_elden_ring/ (engine, storage, UI and self-check), tests/,
scripts/, docs/, assets/, main.py and the unchanged elden_ring_costs.json.
Obsolete reference-only scripts and a personal example path have been removed.
Use Auto Elden Ring 6.0.1 for native menus, save import and current UI fixes.

Original formula APIs are organized under tests/reference/ for regression checks.
