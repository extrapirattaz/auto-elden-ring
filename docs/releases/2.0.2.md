# Auto Elden Ring 2.0.2

Historical release. For the current application, static styles and save rescans, use Auto Elden Ring 6.1.0.

## Changes

- Added an integrated Windows title bar with dragging, minimize/maximize/close
  controls and native resizing, keeping the caption inside the selected theme.

## Downloads

- Auto-Elden-Ring-2.0.2-win-x64.exe: standalone Windows x64 application; Python is not required.
- auto-elden-ring-2.0.2-windows-x64.zip: Windows application with documentation.
- auto-elden-ring-2.0.2-source.zip: exact Python source snapshot paired with this executable.
- RELEASE_MANIFEST.json and SHA256SUMS.txt: version correspondence and SHA-256 hashes.
- VERIFICATION_*.json: verification evidence for this particular build.

Local profiles and game saves are not included. The latest source can be run with Python 3.14 x64. Game data and artwork provenance are documented in the included source documentation.
