# Auto Elden Ring 1.0.1

Historical release. For the current application, static styles and save rescans, use Auto Elden Ring 6.1.0.

## Changes

- Provide a sanitized successor to the original 1.0.0 calculator for public sharing.
- Remove a personal example-path comment and unused configuration.
- Move original formula compatibility references into the historical test folder.
- Format the maintained Python source and provide an English usage guide.
- Preserve original calculator behavior and rebuild the matching x64 EXE and both ZIPs.
- Keep the original 1.0.0 archive local-only; publish 1.0.1 instead.

## Downloads

- Auto-Elden-Ring-1.0.1-win-x64.exe: standalone Windows x64 application; Python is not required.
- auto-elden-ring-1.0.1-windows-x64.zip: Windows application with documentation.
- auto-elden-ring-1.0.1-source.zip: exact Python source snapshot paired with this executable.
- RELEASE_MANIFEST.json and SHA256SUMS.txt: version correspondence and SHA-256 hashes.
- VERIFICATION_*.json: verification evidence for this particular build.

Local profiles and game saves are not included. The latest source can be run with Python 3.14 x64. Game data and artwork provenance are documented in the included source documentation.
