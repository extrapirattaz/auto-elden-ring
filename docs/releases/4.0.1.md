# Auto Elden Ring 4.0.1

Historical release. For the current application, static styles and save rescans, use Auto Elden Ring 6.1.0.

## Changes

- Added an editable current level for the level-713 farming objective.
- Removed its duplicate maximum-level duration card.
- Added runes invested since the starting class and their equivalent farming time.
- Kept investment separate from held runes and left character attributes unchanged.
- Added numerical boundary, legacy-state and real-widget regression checks.

## Downloads

- Auto-Elden-Ring-4.0.1-win-x64.exe: standalone Windows x64 application; Python is not required.
- auto-elden-ring-4.0.1-windows-x64.zip: Windows application with documentation.
- auto-elden-ring-4.0.1-source.zip: exact Python source snapshot paired with this executable.
- RELEASE_MANIFEST.json and SHA256SUMS.txt: version correspondence and SHA-256 hashes.
- VERIFICATION_*.json: verification evidence for this particular build.

Local profiles and game saves are not included. The latest source can be run with Python 3.14 x64. Game data and artwork provenance are documented in the included source documentation.
