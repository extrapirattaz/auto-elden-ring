# Auto Elden Ring 2.0.1

Historical release. For the current application and native-menu fixes, use Auto Elden Ring 6.0.1.

## Changes

- Preserved elapsed duration in the entry field when an ordinary farming test
  is stopped early, so recording cannot restore the previous 60-second value.
- Improved the German golden-horn label.

## Downloads

- Auto-Elden-Ring-2.0.1-win-x64.exe: standalone Windows x64 application; Python is not required.
- auto-elden-ring-2.0.1-windows-x64.zip: Windows application with documentation.
- auto-elden-ring-2.0.1-source.zip: exact Python source snapshot paired with this executable.
- RELEASE_MANIFEST.json and SHA256SUMS.txt: version correspondence and SHA-256 hashes.
- VERIFICATION_*.json: verification evidence for this particular build.

Local profiles and game saves are not included. The latest source can be run with Python 3.14 x64. Game data and artwork provenance are documented in the included source documentation.
