smithing materials and measured rune farming. This is a sanitized maintenance

the personal music-path example have been removed; runtime calculations retain
their original implementation. Python formatting and comments use English.

The release includes a matching source ZIP, Windows x64 ZIP, standalone EXE,
SHA256SUMS.txt and RELEASE_MANIFEST.json. The packaged self-check and original
test suite run before these files are published locally.

Original formula APIs are organized under tests/reference/ for regression checks.
